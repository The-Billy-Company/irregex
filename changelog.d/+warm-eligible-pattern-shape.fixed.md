`session.warm_eligible` (the Python leg's warm/cold router, ADR-352 rung 2.5) accepted any non-scoped request regardless of pattern shape, so a `\n`, NUL, or empty pattern was routed to the resident daemon — whose whole-document engine can match across line boundaries where the cold per-line walk cannot, a silent warm≠cold divergence. It now declines an empty, `\n`-, or NUL-bearing pattern up front, mirroring `session/request.zig::classify` term-for-term, so every request the two accept answers byte-identically on both paths.
