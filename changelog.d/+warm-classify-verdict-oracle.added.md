`GIST_DEBUG_WARM=1` now prints the classifier's routing verdict — `gist: [eligible]` / `gist: [ineligible]` — *before* the daemon dial, so a cold outcome from "ineligible argv" is distinguishable from "eligible but no daemon listening". This makes `src/runtime/session/request.zig::classify` observable independently of any running daemon, giving the cross-binding parity test a daemon-free oracle for the exact argv the resident path will accept.
