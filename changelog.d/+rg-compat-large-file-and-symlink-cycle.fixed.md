Fixed two `rg`-compat bugs found by adversarial-testing against ripgrep's own issue history: files at/above the 4 MiB indexing-corpus budget silently returned zero matches instead of being searched in full (the read path reused `per_file_cap` as a hard ceiling; it now keeps reading past it), and `-L`/`--follow` hung forever on a self-referential symlink cycle (the depth counter alone didn't stop it; the walk now also tracks each ancestor's realpath and refuses to re-descend into one already on the current DFS stack, while still following legitimate non-cyclic diamonds).
